DATA STORAGE
ECTO currently stores operational state locally in the browser using localStorage.
The Concept 006 key is: ecto_containment_006
On first run, 006 imports prior saved state from Concept 005/003/002 when available.
This is device/browser/site-origin local data. It is not cloud synced and is not contained inside index.html.
Clearing browser/site data, using a different browser/origin, or some deployment changes can therefore create a fresh database.

Open index.html in a modern browser.
